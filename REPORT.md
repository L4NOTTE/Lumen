# Lumen 0.4.57 для Windows

Сетевой блокировщик получает имя обычного HTTP или HTTPS хоста напрямую из адреса. Полный разбор по-прежнему применяется к адресам с портами, нестандартным синтаксисом и международными доменами. При навигации используется уже разобранный адрес.

| Сценарий | 0.4.56 | 0.4.57 |
|---|---:|---:|
| 500 000 проверок адресов, медиана 12 прогонов | 107,79 мс | 48,68 мс |
| Серия из 120 запросов на локальной странице, медиана 4 запусков на сборку | 37,55 мс | 37,15 мс |

В первом сценарии обе версии блокировали 200 000 одинаковых запросов на прогон. Во втором каждая сборка обрабатывала одинаковые HTTP-ответы с включённым базовым блокировщиком. Разница на уровне страницы мала. Внешние сайты, запуск и память в этой серии не измерялись.

Все 47 тестов Rust прошли. Проверены подпись манифеста и хеш установщика. У установщика нет Authenticode.
