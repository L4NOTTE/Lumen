Расширения

Установить из Chrome Web Store

Вставьте ссылку из Chrome Web Store, ID или путь к распакованному расширению. После установки обновите страницы. Кнопка «Открыть» показывает popup или настройки расширения. Совместимость зависит от API WebView2; установка не гарантирует работу всех функций.

Установленные

В этой папке лежат файлы установленных расширений.

Настройки

Браузер по умолчанию

Открыть системные настройки для ссылок HTTP и HTTPS. Выбор подтверждается в Windows.

Тема

Тема применяется к интерфейсу браузера. Сайты выбирают оформление сами.

Акцентный цвет

Шрифт интерфейса

Фон главного экрана

Фото уменьшается и хранится только на этом компьютере. Фон показывается на стартовой странице новой вкладки.

Память и скорость

Выгружать фоновые вкладки из памяти через:
Эконом-режим движка (нужен перезапуск):
Эконом-режим: облегчённый режим Chromium, не хранит страницы для кнопки «Назад», не больше трёх процессов. Памяти уходит меньше, но возможны небольшие задержки на тяжёлых сайтах.

При запуске

Вернуть вкладки: откроется то, что было в прошлый раз (загружается только активная вкладка, остальные ждут своего часа и не тратят память).

Блокировка рекламы

Блоки с пометкой «Реклама»

Скрывает рекламные карточки по метке «Реклама», «Соцреклама» или «erid» — помогает там, где реклама приходит с самого сайта (например, Яндекс).

Что заблокировано

Усиленная: списки EasyList, RU AdList, AdGuard Russian и uBlock проверяют каждый запрос страницы и скрывают пустые рекламные места. Занимает больше памяти (десятки МБ). Базовая: лёгкий встроенный список доменов.
