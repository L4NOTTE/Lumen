# Проверка Lumen 0.4.19 для Windows

Готовый бинарник прошёл 19 локальных проверок безопасности. Нативный набор прошёл 40 тестов, включая запрет веб-адресов со встроенными учётными данными. Подпись манифеста и SHA-256 установщика проверены.

По локальному снимку RustSec записей категории vulnerability: 0. Предупреждений: 4. [Результаты RustSec](dependencies.json)

Повторная косметическая фильтрация больше не создаёт отдельный поток для каждой загрузки страницы. Замеры быстродействия, внешний трафик и Linux в этот прогон не входили.
