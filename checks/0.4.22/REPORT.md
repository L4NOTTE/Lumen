# Перетаскивание вкладок в Lumen 0.4.22

Панель ищет место двоичным поиском по центрам вкладок. Если место не меняется, обновляется только смещение перетаскиваемой вкладки. Когда место меняется, обновляются только пересечённые вкладки. При завершении перетаскивания координаты читаются одним проходом перед запуском анимаций.

| Сценарий, 1200 кадров модели | 0.4.21 | 0.4.22 |
| --- | ---: | ---: |
| 24 вкладки, присваивания transform | 28 800 | 1 329 |
| 60 вкладок, присваивания transform | 72 000 | 1 561 |

Сценарий исполняет код обеих версий с моделью DOM. В нём проверены движения в обе стороны, резкие развороты и выход за границу панели. Числа отражают обновления свойств, а не частоту кадров. Время создания первого отдельного окна и задержка кадра отдельно не измерялись.

Отдельный тест готовой Windows-сборки перетащил локальную страницу в новое окно, затем обратно за оставшуюся вкладку. Позиция проверена через Windows UI Automation. Сервер зафиксировал ровно одну загрузку страницы. Прошли 40 нативных тестов.
