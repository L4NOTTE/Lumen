# Производительность и безопасность Lumen 0.4.20 для Windows

## Загрузка и анимация

Три запуска каждой версии с новым профилем. В каждом запуске одна вкладка последовательно загружала 12 локальных HTML-документов через HTTP. Тест учитывает DOM-событие load. Сеть, реальные сайты и частота кадров отдельно не измерялись.

| Медиана | 0.4.19 | 0.4.20 |
| --- | ---: | ---: |
| Запуск до первой загруженной страницы | 607 мс | 578 мс |
| Загрузка последующей страницы | 8,9 мс | 9,0 мс |
| Интервал между первой и последней страницами | 209 мс | 211 мс |
| Закрытие окна до выхода процесса | 168 мс | 127 мс |
| Частная память дерева процессов после паузы | 323,3 МиБ | 322,1 МиБ |
| Суммарный working set после паузы | 571,3 МиБ | 573,2 МиБ |

Первый запуск новой версии занял 1469 мс. Этой выборки недостаточно для вывода об ускорении запуска. Закрытие ускорилось примерно на 24 процента в этом сценарии. Суммарный working set может включать общие страницы памяти.

## Память и процессы

Windows UI Automation открывала 10 дополнительных вкладок, закрывала их и ждала три секунды. Выполнено три цикла на каждой версии. Число наблюдаемых процессов в каждом цикле менялось с 8 до 18 и возвращалось к 8. После закрытия окна оба прогона завершили все наблюдавшиеся процессы.

| Частная память после закрытия вкладок | 0.4.19 | 0.4.20 |
| --- | ---: | ---: |
| Исходное состояние | 322,4 МиБ | 316,8 МиБ |
| После первого цикла | 497,8 МиБ | 494,8 МиБ |
| После второго цикла | 538,4 МиБ | 537,0 МиБ |
| После третьего цикла | 464,6 МиБ | 463,7 МиБ |

Часть памяти остаётся выделенной при открытом окне. За три цикла монотонного роста не обнаружено. Причину остаточного выделения и поведение в многочасовом прогоне этот замер не устанавливает.

## Безопасность

- Локальная страница попыталась открыть шесть вкладок без пользовательского действия. Сборка 0.4.19 загрузила шесть, 0.4.20 заблокировала все. Разрешение проверяется по IsUserInitiated в WebView2.
- Объём сбора DOM для косметической фильтрации ограничен. Запоздалый ответ предыдущей загрузки игнорируется. Загрузчики фильтров и обновлений получают путь к системному curl через Windows API.
- Прошли 40 нативных тестов и 19 локальных проверок, включая изоляцию инкогнито и отсутствие отладочного порта. По локальной базе RustSec найдено четыре предупреждения и ноль записей категории vulnerability. Подпись манифеста и хеш установщика проверены.
- Этот прогон охватывает Windows, локальные страницы и перечисленные сценарии. Уязвимости движка, расширения, внешний трафик и Linux требуют отдельных проверок.
