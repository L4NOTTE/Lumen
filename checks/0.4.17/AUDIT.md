# Повторная проверка защиты Lumen 0.4.17

В Windows удалён файловый почтовый ящик переноса вкладок. Старый механизм принимал URL из файлов профиля и создавал новую страницу. Вытаскивание вкладки и её возврат теперь выполняются в рамках одного процесса. Панель отдельного окна принимает два фиксированных сообщения и проверяет документ-источник.

Автообновление принимает только подписанные манифесты с более высокой версией и действующим сроком. Установщик проверяется по размеру и SHA-256 до запуска. Windows ждёт итоговый код установщика и записывает результат. На момент проверки репозиторий L4NOTTE/Lumen не содержал опубликованных релизов, поэтому установка через публичный канал не проверена.

Локальный снимок RustSec не выявил записей категории vulnerability. Остались три предупреждения о сопровождении и одно о rand 0.7.3. [Отчёт cargo-audit](dependencies.json)

Локальный аудит проверяет границы IPC, геолокацию, CDP, изоляцию инкогнито и утечки в файлы профиля. Аудит движка, внешнего трафика, сторонних расширений и Linux в этот прогон не входит.
nФинальная сборка прошла 39 тестов Windows и 19 локальных проверок безопасности. [Результаты](blackbox-results.json)
