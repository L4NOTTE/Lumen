# Проверка оптимизации Lumen 0.4.21

Три прогона каждой версии в основном окне Windows с отдельным профилем, по 12 последовательных локальных HTTP-страниц.

| Медиана | 0.4.20 | 0.4.21 |
| --- | ---: | ---: |
| События изменения session.json | 7 | 2 |
| Загрузка локальной страницы | 9,2 мс | 8,7 мс |
| Интервал между первой и последней страницами | 213 мс | 209 мс |
| Частная память после паузы | 323,9 МиБ | 320,3 МиБ |

События измерены FileSystemWatcher и отражают уведомления о файле, а не число физических операций диска. После штатного закрытия последний URL присутствовал в сеансе во всех шести прогонах. Небольшой разброс времени и памяти не позволяет заявить об ускорении загрузки или снижении памяти. Работа панели вкладок отдельно по времени кадра не измерялась.

Сборка прошла 40 тестов Windows и 19 локальных проверок безопасности. При аварии изменения сеанса, ожидающие отложенной записи, могут не восстановиться.
