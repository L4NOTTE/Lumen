# Проверка Lumen 0.3

## Собрано и проверено

- Windows x64 release exe успешно собран.
- Rust: 6 обычных регрессионных тестов успешно; дополнительные CRX/Desktop-тесты исключены из обычного запуска.
- JavaScript адаптера Shazam: проверены ожидание явного нажатия, передача аудиопотока, подавление обратного воспроизведения, остановка экранного захвата, отказ источника без аудио и изоляция от других расширений.
- В чистом тестовом профиле установлено официальное расширение Shazam из ранее скачанного пакета 2.7.0. Подтверждены оригинальный ID, наличие адаптера внутри реальной chrome-extension страницы, доступность getDisplayMedia, secure context и загрузка UI расширения. Звук и экран не записывались.
- Встроенный полный DevTools подключён к тестовой вкладке через локальный сервер WebView2. Подтверждены шапка Lumen, заголовок Lumen DevTools 0.3, верхний отступ 40 px и настоящие Elements, Styles, Computed, Layout.
- Через API frontend выполнено переключение: Console; Sources/Page; Network; Performance/Interactions; Application. Во всех случаях подтверждена соответствующая активная вкладка интерфейса.
- Предыдущий нативный тест видимости окна после анимации, maximize и двух циклов fullscreen проходил успешно.

## Что изменено

Вместо панели JSON-снимков встроен полный frontend из установленного WebView2 с локальным подключением CDP и оформлением Lumen.
F12 теперь открывает эту панель. Её закрытие отсоединяет frontend, смена вкладки переподключает.
Переходы из привилегированного DevTools ограничены локальным frontend; внешние ссылки направляются в обычные вкладки.

Для Shazam добавлен адаптер системного захвата со звуком, который ждёт явного выбора пользователя.
Shazam открывается в устойчивой вкладке, а при ручном запуске как popup не закрывается при потере фокуса на системном диалоге.
Системный звук не воспроизводится обратно в динамики через источник Shazam, чтобы не создавать петлю.

Убраны внешние отступы содержимого и нативная светлая рамка, исправлены выступающие focus outlines.
Версия пакета и установщика — 0.3.0. Иконка — новая световая монограмма L.

## Ограничения

Успешное распознавание настоящей песни в Shazam автоматически не проверялось: для этого нужен выбор источника и разрешение на передачу звука.
Адаптер использует системный захват, а не нативный Chrome tabCapture одной вкладки. Возможность передать аудио зависит от Windows, WebView2 и выбранного источника.
Все специальные интеграции полного DevTools (например, OS workspace и frontend-расширения) отдельно не проверялись.
Все разрешения экрана/DPI, fullscreen конкретного YouTube-видео и каждый визуальный пиксель вручную не проверены.

Встроенный frontend использует ресурсы локального WebView2; скачанные исследовательские исходники Chromium в архивы не включены.
Установщик локально не собирался. Его соберёт приложенный GitHub Actions workflow.
