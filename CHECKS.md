# Проверка 0.4.0 — Windows + Linux preview

- Windows: cargo test — 8 успешно, 2 теста со специальными условиями пропущены; release собран. После разделения backend выполнены реальные проверки плавного drag и сохранения масштаба после перезапуска/инкогнито.
- Shared UI: node tools/test-shazam-capture.mjs успешно; ссылки README и Cargo metadata проверены.
- Linux: cargo check для x86_64-unknown-linux-gnu, включая тестовые модули, успешно проверил Rust-код приложения и настоящие GTK/WebKitGTK-биндинги. На Windows использовался временный rustc-wrapper: только системные build.rs GTK-семейства компилировались с cfg(docsrs), чтобы не выполнять pkg-config отсутствующих Linux-библиотек. Код приложения и GTK/WebKit API не подменялись заглушками. Это НЕ нативная сборка, НЕ проверка ABI/линковки и НЕ запуск Linux.
- CI Linux: добавлены обычные cargo test/build без wrapper, графический Xvfb smoke-тест с настоящим ответом UI и упаковка .deb/.tar.gz. Здесь workflow не запускался; готовых Linux-пакетов пока нет.
- GTK-разметка использует Box/Stack/Paned, а не абсолютные размеры WebView, чтобы не навязывать минимальную ширину 1200 px и не ломать масштаб/Wayland. Inspector подключён через WebKit attach/open-window сигналы к боковой панели. Нативная проверка этих действий остаётся задачей Linux CI и реального рабочего стола.
- Отличия Linux, инструкции и статус: LINUX.md. Chrome-расширения и Chromium DevTools в Linux не заявляются.

## Исправления

- Shazam открывается через 🧩 → Открыть в компактном popup 420×500, а не во вкладке.
- Старые вкладки Shazam из сессии предыдущей версии больше не восстанавливаются.
- Нажатие распознавания Shazam запускает WASAPI loopback устройства вывода Windows напрямую. Диалога выбора экрана и дополнительной кнопки источника больше нет.
- В расширение передаётся поток через Web Audio MediaStream; обратное воспроизведение подавлено для предотвращения эха.
- Слышен системный звук, включая другие приложения. Это не изолированный звук одной вкладки.
- Захват прекращается при остановке расширением, закрытии/перезагрузке popup, ошибке либо через 60 секунд.
- Убраны отдельная кнопка распознавания музыки и Ctrl+M.
- У кнопок отключены scale, transition, box-shadow и outline; это также относится к кнопкам окна.
- Полноценный DevTools в боковой панели сохраняется.
