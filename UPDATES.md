# Обновления Lumen

Начиная с 0.4.8 установленный браузер проверяет `lumen-update.json` в последнем релизе `L4NOTTE/Lumen`. Подходящая версия загружается в фоне и применяется при закрытии окна, если загрузки браузера завершены. Для Windows используется установщик Inno Setup. Для Linux заменяется пользовательский бинарник `~/.local/bin/lumen`. Для системного `.deb` используется менеджер пакетов. На Linux для проверки обновлений нужен `/usr/bin/curl`.

Манифест проверяется встроенным ключом Ed25519. Он содержит версию, срок действия, размер и SHA-256 каждого артефакта. Браузер проверяет файл повторно перед применением. Подпись манифеста авторизует обновление внутри Lumen. Authenticode для доверия Windows настраивается отдельно по SIGNING.md.

## Предварительные сборки

Тестовую сборку с оптимизацией памяти можно опубликовать под тегом `v0.4.24-preview.1` с отметкой **Pre-release** и приложить ZIP с `lumen.exe` для ручной установки. У текущего тестового EXE внутренняя версия `0.4.23`. Укажите это в описании предварительного релиза.

Для предварительных релизов оставляйте манифест автообновления в стабильном канале. Обновлятор принимает только числовую версию из трёх частей, например `0.4.24`, и ищет манифест по пути `releases/latest/download/lumen-update.json`.

## Стабильные релизы

Обновите внутреннюю версию, соберите установщик и проверьте его. Сформируйте манифест по финальным файлам. Если файл меняется после подписи манифеста, подпишите манифест заново.

Публикуйте файлы в GitHub Releases в репозитории `L4NOTTE/Lumen` под тегом `v<версия>`.

- `LumenSetup.exe` для Windows x64.
- `lumen-linux-x64` для Linux x64 при наличии проверенной сборки.
- `lumen-update.json`, подписанный после подготовки всех файлов, которые войдут в обновление. Для выпуска только под Windows достаточно установщика.

Пример подписи Windows-выпуска в PowerShell на машине владельца ключа:

```powershell
./tools/sign-update-local.ps1 -Version 0.4.24 -WindowsInstaller ./LumenSetup.exe -Output ./lumen-update.json -ProtectedKey 'C:\path\to\private.dpapi'
```

Для выпуска с Linux добавьте `-LinuxBinary ./lumen-linux-x64`. Версия должна соответствовать собранному исходному коду и тегу. Срок действия манифеста составляет 30 дней. Приватный ключ хранится вне исходников под DPAPI текущего пользователя Windows. Сохраняйте доступ к ключу, чтобы установленный браузер мог принимать будущие релизы.

Для CI скрипт `tools/sign-update.cjs` принимает ключ PKCS#8 Ed25519 в Base64 через секрет `LUMEN_UPDATE_PRIVATE_KEY_BASE64` или стандартный ввод. Запускайте подпись только после проверки финальных файлов. Установка 0.4.8 требуется один раз. Lumen проверяет канал при запуске и каждые шесть часов до получения подходящего обновления. На Windows итог попытки установки записывается в %LOCALAPPDATA%/Lumen/update-status.txt. Нативный цикл через опубликованный канал проверяется после первого публичного релиза с подписанным манифестом.
