# Lumen 0.3

Браузер Windows на Rust, tao, wry и Microsoft Edge WebView2.

## Запуск обновления

Закройте все прежние окна Lumen, включая окна расширений, затем запустите lumen.exe из нового архива.
Несколько окон используют общую среду WebView2: старая работающая среда может сохранить прежние параметры движка.
Версия окна Windows — Lumen 0.3; подсказка при наведении на логотип также содержит версию.

## Полный DevTools в оформлении Lumen

Кнопка </> и F12 / Ctrl+Shift+I открывают полноценный интерфейс разработчика справа.
Используется frontend установленного WebView2, который соединяется с активной вкладкой по локальному CDP.
Внешняя загрузка frontend не требуется. Порт привязан к 127.0.0.1 и сохраняется в профиле.

Доступны настоящие Elements/Styles/Computed/Layout, Console, Sources, Network, Performance,
Memory, Application и остальные инструменты, предоставляемые текущим WebView2 Runtime.
Оформление использует шапку Lumen, его тему, шрифт, акцент и внутренние границы.
Это полный frontend движка с оформлением Lumen, а не независимая повторная реализация всех его внутренних механизмов.
Особые интеграции с ОС и расширениями зависят от возможностей WebView2 и hosted frontend.

Потяните левую границу панели, чтобы изменить ширину. F12 и × закрывают её.
↻ переподключает к активной странице; ↗ открывает системный инспектор отдельным окном.
При смене вкладки инспектор переподключается. Закрытие панели завершает её соединение с вкладкой.
Внешние ссылки из DevTools открываются в обычной вкладке браузера.

## Shazam

Для официального расширения mmioliijnhnoblpgimnlajmefafdfilb добавлен адаптер захвата:
WebView2 не предоставляет обычный Chrome-контекст tabCapture для вкладок Lumen.
Поэтому Shazam использует явный системный выбор источника со звуком.

1. Откройте Shazam через 🧩 → Открыть. Он откроется во вкладке.
2. Нажмите кнопку распознавания Shazam.
3. В появившейся полосе Lumen нажмите «Выбрать источник звука».
4. В системном диалоге выберите экран и включите передачу системного звука.

Если выбранный источник не предоставляет аудиодорожку, Lumen покажет сообщение и предложит повторить выбор.
Передаётся системный звук выбранного источника, включая другие звучащие приложения; это не изолированный захват одной вкладки.
В Shazam передаётся только аудио. Захват экрана прекращается вместе с аудио или при закрытии страницы.
Обратное воспроизведение захваченного системного аудио подавлено, чтобы избежать эха.
Без нажатия и разрешения в системном диалоге захват не начинается.

Адаптер проверен в реальном контексте установленного официального расширения и на искусственных потоках.
Распознавание реальной песни требует вашего разрешения на звук и в автоматических тестах не выполнялось.
Если система/WebView2 не предлагает передачу звука для выбранного источника, этот путь распознавания будет недоступен.

VK Next использует прежнюю установку WebView2; изменение захвата применяется только к официальному Shazam.

## Визуальные исправления

Убран внешний отступ WebView, включая fullscreen, и контрастный DWM-контур Windows 11.
Клавиатурная подсветка кнопок рисуется внутри границ; мышиный фокус не создаёт выступающей белой рамки.
Окно растягивается за верхнюю границу и углы строки заголовка.
Темы и DPI учитываются при расчёте размеров панелей; минимальное окно — 480×320 логических пикселей.
Сохраняются новая световая иконка Lumen, масштаб 25–500% и короткие анимации с учётом reduced motion.

## Остальные возможности

Вкладки, история, восстановление сессии, быстрые ссылки, Google/Яндекс/DuckDuckGo,
темы и фоны, блокировщик adblock с пользовательскими списками, экономия памяти,
инкогнито и отдельное распознавание через AudD с собственным API-ключом.
Перенос вкладки между процессами передаёт адрес с перезагрузкой, без форм и состояния JavaScript.

## Сборка

Нужны Rust stable x86_64-pc-windows-msvc, Visual Studio Build Tools C++ и WebView2 Runtime.

```powershell
cargo test --locked
node tools/test-shazam-capture.mjs
cargo build --release --locked
```

Готовый exe: target/release/lumen.exe.
Inno Setup 6: `iscc installer/lumen.iss`.
Загрузите содержимое исходного архива в корень GitHub-репозитория, включая .github.
Workflow проверит Rust и JS-тесты, соберёт exe и установщик.

Данные: %LOCALAPPDATA%/Lumen. Переменная LUMEN_DATA_DIR задаёт отдельный корень тестовых данных.
Для интеграционных проверок есть tools/verify-devtools.ps1 и tools/verify-shazam.ps1.
LUMEN_TEST_HIDDEN=1 позволяет запускать отдельный тестовый экземпляр без видимого окна.
Подробности проверки — CHECKS.md.
