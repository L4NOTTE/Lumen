Lumen — браузер с собственным интерфейсом и нативной логикой на **Rust**. Вкладки, управление окнами, горячие клавиши, настройки и интеграция с Windows реализованы на Rust. В Windows сайты отображает **Microsoft Edge WebView2** на основе Chromium, в Linux — **WebKitGTK**. Интерфейс браузера создан на HTML, CSS и JavaScript.

## Платформы

Текущая Windows-версия — 0.5.4. Работа над Linux-портом приостановлена. Дальнейшие сведения о Linux относятся к ранее подготовленному preview.

В 0.5.3 открытые веб-вкладки возвращаются в свои окна при восстановлении сеанса. Перенос доступен из меню вкладки. Незавершённые загрузки и ошибки записи сеанса блокируют перезапуск для обновления. Для публикации комплекта используйте тег `v0.5.3` с отметкой Latest.

**Установка Linux из GitHub:** `git clone https://github.com/L4NOTTE/Lumen.git`, затем `cd Lumen` и `bash tools/install-linux.sh`. Зависимости, Rust и обновление через `git pull --ff-only` описаны в [LINUX.md](LINUX.md). Это текущий WebKitGTK preview, а не завершённая Chromium-версия.

**Windows x64** — основная версия. **Ubuntu 24.04, Fedora 44 и Arch Linux x86_64** — цели Linux-порта. Для Fedora и Arch добавлены задания нативной сборки и тестов. Готовность пакетов и поведение в графической среде проверяются отдельно.

Linux использует другой движок: Chrome-расширения, Shazam/VK Next и оформление Chromium DevTools не перенесены. Linux-ветка подготовлена для сборки в Actions, но её нативный запуск на этой рабочей машине не проверен. Возможности, ограничения и получение `.deb` описаны в [LINUX.md](LINUX.md).

## Возможности Windows

- **Вкладки:** создание, восстановление закрытых вкладок, перестановка перетаскиванием и перенос между окнами. Ссылки средней кнопкой открываются в фоне.
- **Внешний вид:** светлая и тёмная темы, акцентные цвета, настройка шрифтов и фона новой вкладки.
- **Навигация:** адресная строка, выбор поисковика, история, избранное и быстрые ссылки. Новая вкладка подсказывает недавние запросы из локальной истории и прокручивает их внутри списка.
- **Загрузки:** отдельный раздел по кнопке на панели или Ctrl + J; прогресс, отмена, поиск по истории, открытие файла и папки. Совпадающие имена получают числовой суффикс.
- **Масштаб:** кнопки на панели, горячие клавиши и Ctrl + колесо над страницей; значение сохраняется для каждого сайта между запусками.
- **DevTools** открывается из обычной вкладки кнопкой в панели браузера или клавишей F12. В Windows используется штатное окно WebView2, в Linux — инспектор WebKitGTK.
- **Блокировка рекламы:** сетевые фильтры и скрытие рекламных карточек, включая обработку закрытого Shadow DOM на Яндексе.
- **Расширения:** доступны в обычных окнах Windows. Восстановлены popup и адаптер захвата для Shazam.
- **Режимы работы:** инкогнито, усыпление неактивных вкладок и экономный режим. GPU-отрисовка WebView2 остаётся доступной в обоих режимах.
- **VPN:** VLESS и HTTPS-подписки через Xray-core для трафика браузера.

Совместимость расширений зависит от доступных API WebView2. Блокировка рекламы развивается: на отдельных сайтах объявления могут сохраняться. При переносе между окнами Windows сохраняет открытый WebView2 вкладки. Результаты проверок и известные ограничения собраны в [CHECKS.md](CHECKS.md).

## Запуск

Портативный комплект находится в `Portable.x64.zip`. Распакуйте архив целиком и запустите `Portable.x64/Lumen-Portable/Lumen.cmd`. Для VPN нужен комплектный `xray.exe`, который входит также в установщик.

1. Полностью закройте предыдущие окна Lumen и расширений.
2. Для установки запустите `LumenSetup.exe`. Для портативной версии распакуйте ZIP и запустите `Lumen.cmd`, чтобы профиль хранился рядом с браузером.

Для работы нужны **Windows x64** и установленный **Microsoft Edge WebView2 Runtime**. Runtime обновляется через Microsoft. После обновления Runtime полностью перезапустите Lumen.

После обновления правил блокировки включите щит и скрытие рекламных меток в настройках, затем перезагрузите открытые страницы.

## Горячие клавиши

| Сочетание | Действие |
| --- | --- |
| Ctrl + T | Новая вкладка |
| Ctrl + W | Закрыть вкладку |
| Ctrl + Shift + T | Восстановить закрытую вкладку |
| Ctrl + Tab / Ctrl + Shift + Tab | Следующая / предыдущая вкладка |
| Ctrl + 1…9 | Перейти к вкладке по номеру |
| Ctrl + L / F6 | Выделить адресную строку |
| Alt + ← / Alt + → | Назад / вперёд |
| Ctrl + колесо | Изменить масштаб страницы |
| Ctrl + ↑ / Ctrl + ↓ | Увеличить / уменьшить масштаб |
| Ctrl + + / Ctrl + − | Увеличить / уменьшить масштаб |
| Ctrl + 0 | Сбросить масштаб |
| F12 / Ctrl + Shift + I | Открыть DevTools страницы |
| F11 | Полноэкранный режим |
| Ctrl + H | История |
| Ctrl + J | Загрузки |
| Ctrl + Shift + N | Окно инкогнито |
| Ctrl + , | Настройки |

**Ctrl + Z** не используется для навигации: сочетание остаётся для отмены ввода в текстовых полях и редакторах сайтов.

Файлы сохраняются в системную папку загрузок. Очистка списка не удаляет файлы. История последних 200 загрузок сохраняется между запусками; инкогнито не записывает её на диск, но сами скачанные файлы остаются. При закрытии браузера активные загрузки прерываются; автоматическое возобновление пока не реализовано.

## Сборка из исходников

Стек проекта: **Rust · tao · wry · WebView2 · HTML/CSS/JavaScript**.

Команды выполняются на Windows из каталога с `Cargo.toml`, с установленным Rust stable и инструментами сборки MSVC. Зависимости Rust поставляются в `vendor`.


```powershell
cargo test --locked --offline
cargo build --release --locked --offline
```

Готовый файл: `target/release/lumen.exe`.

Для проверки адаптера Shazam используется Node.js 22:

```powershell
node tools/test-shazam-capture.mjs
```

Для локальной сборки установщика нужен Inno Setup 6:

```powershell
iscc installer/lumen.iss
```

Установщик появится в `installer/Output/LumenSetup.exe`.

## Сборка через GitHub Actions

Загрузите **содержимое архива исходников** в корень репозитория, включая скрытую папку `.github`. Рядом с README должны находиться `Cargo.toml`, `Cargo.lock`, `src`, `ui` и остальные файлы проекта.

Workflow [build-windows](.github/workflows/build.yml) запускается для pull request, при отправке изменений в `main` и вручную через **Actions → build-windows → Run workflow**. Он проверяет команды от веб-страниц, подписи обновлений и загрузки в собранном браузере, затем собирает установщик. Аудит зависимостей запускает [security-audit](.github/workflows/security.yml). Артефакт **lumen-windows** доступен со страницы успешного запуска.

## Исправления 0.5.1 для Windows

- Файлы HTML и внешние ссылки, открытые через Windows, передаются уже работающему обычному процессу Lumen того же профиля и исполняемого файла.
- Повторный запуск без адреса переводит фокус на существующее окно.
- Вкладки локальных файлов и внешних ссылок оказываются в общем процессе браузера и используют обычный перенос между его окнами.
- Если основное окно закрыто, новый файл или ссылка открывается в доступном отделённом окне.
- Профили, инкогнито и служебные вторичные процессы остаются раздельными.
- Добавлена автоматическая проверка одновременного открытия HTML и URL, перехода по ссылке из HTML, повторного запуска и независимости профилей.

После установки 0.5.1 один раз полностью закройте окна предыдущей версии, затем откройте Lumen снова. Для открытия HTML через Проводник используйте установленную 0.5.1, связанную с этим типом файлов в Windows.

## Изменения 0.5.0 для Windows

Версия 0.5.0 для Windows, подготовленная к выпуску 18 ноября 2026 года.

- Версия Windows обновлена до 0.5.0.
- Из настроек удалена карточка «О браузере» с демонстрацией этапов рендеринга и её пункт навигации. Блок разработчика и установленная версия в разделе обновлений сохраняются.
- При запуске Lumen в фоне проверяет стабильный релиз GitHub. После проверки подписи манифеста новая версия вызывает внутреннее уведомление один раз за запуск. Уведомление видно около семи секунд и не задерживает открытие окна.
- Установочная сборка продолжает фоновую загрузку проверенного обновления. Портативная сборка сообщает о новой версии и предлагает скачать ZIP. Равная или более старая версия уведомление не вызывает.
- Импорт VPN обрабатывает сжатые ответы подписок. Ограничение применяется к распакованному потоку, его размер ограничен двумя МиБ.
- Служебные записи подписки с нулевым UUID, портом 1 и security=none распознаются. Если подписка содержит только такие записи, Lumen показывает понятное сообщение. При смешанном списке рабочие серверы сохраняются.
- Серверы с TLS или REALITY ставятся выше записей без шифрования. Записи без шифрования проходят проверку закреплённого Xray и могут требовать отдельного подтверждения.
- Импорт, выбор сервера, поиск доступного, проверка подключения и отключение VPN доступны в обычных отделённых окнах, включая случай закрытого основного окна.
- Изменение VPN требует перезапуска общего профиля. Открытые HTTP/HTTPS-вкладки всех окон сохраняются и восстанавливаются в основном окне. Перед переключением нужно завершить загрузки и закрыть окна инкогнито и расширений.
- Локальные .html и .htm, явно переданные через Windows при запуске, открываются первыми. Добавлена регистрация этих форматов в возможностях Lumen. Сохранённые веб-вкладки восстанавливаются в фоне.
- Локальный файл допускается только для вкладки, созданной явным запуском файла. Произвольные переходы сайтов к file:// и сетевые UNC-пути этим механизмом не разрешаются.
- В контекстном меню страницы доступны «Копировать адрес ссылки», «Сохранить изображение как…» и «Копировать URL картинки». Сохранение изображения использует штатную команду WebView2 и существующую обработку загрузок.
- Стрелки назад и вперёд различаются цветом по истории конкретного окна. Кнопки остаются кликабельными.
- При отключении блокировщика освобождается движок усиленных фильтров и очищается очередь косметической обработки. Запоздавшие результаты фоновой сборки отбрасываются. При повторном включении фильтры загружаются снова.
- При выключенной блокировке рекламы фоновая сборка и обновление усиленных фильтров не запускаются.

Подробности проверок приведены в [CHECKS.md](CHECKS.md), сравнение версий — в [PERFORMANCE.md](PERFORMANCE.md), безопасность — в [SECURITY.md](SECURITY.md). Порядок обновления описан в [UPDATES.md](UPDATES.md).

- Масштаб сохраняется для каждого сайта и восстанавливается при повторном открытии, новой вкладке и перезапуске.
- Ctrl + 0 сбрасывает сохранённое значение до 100%. В инкогнито изменения действуют только в текущем окне и не записываются в обычный профиль.
- У новой вкладки отдельное сохранённое значение масштаба.

## Что нового в 0.3.12

- Новые контурные SVG-иконки DevTools и шапка Lumen.

## Что нового в 0.3.11

- Сокращены повторные вызовы видимости и размеров WebView при переключении вкладок.
- Одинаковые состояния не отправляются интерфейсу повторно; скрытые DevTools не получают обновления, неизменившиеся настройки не перерисовываются.
- Блокировщик проверяет изменившиеся участки DOM; при больших изменениях и смене правил выполняется полный обход. Сложные процедурные правила сохраняют проверку всего документа.
- Добавлены воспроизводимые замеры запуска, вкладок, процессов WebView2 и обхода DOM. Условия и результаты — в [PERFORMANCE.md](PERFORMANCE.md).
