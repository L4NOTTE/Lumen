# Lumen — лаконичный браузер для Windows на Rust

Свой интерфейс (вкладки, адресная строка, стартовая страница) на `tao` + `wry`.
Страницы отображает системный WebView2 (Chromium от Microsoft).

## Возможности
- Вкладки, Ctrl+T / Ctrl+W / Ctrl+L / F5, ссылки с `target=_blank` открываются во вкладке
- Поиск: Google, Яндекс, DuckDuckGo (выбор в адресной панели, запоминается)
- Блокировка рекламы и трекеров (кнопка 🛡):
  - встроенный список доменов (Google Ads, Яндекс.Директ/Метрика, Adfox, mail.ru, VK и др.)
  - блокировка переходов на рекламные домены
  - перехват `fetch` / XHR / `sendBeacon` / динамических `script`, `iframe`, `img`
  - скрытие рекламных блоков через CSS
  - свои списки: положите `*.txt` в `%LOCALAPPDATA%\Lumen\filters\`
    (поддерживаются `||домен^`, `##селектор` и формат hosts; подойдут EasyList, AdGuard, RU AdList)
- Защита:
  - режим HTTPS-only: `http://` автоматически заменяется на `https://`
  - SmartScreen WebView2 включён
  - DevTools отключены в release-сборке
  - отдельный профиль в `%LOCALAPPDATA%\Lumen\profile`
- Оптимизация: release-профиль с LTO, `codegen-units=1`, `panic=abort`, `strip`; параллельная загрузка файлов

## Сборка
1. Установите Rust (https://rustup.rs) с целью `x86_64-pc-windows-msvc` и Visual Studio Build Tools (C++).
2. `cargo run` — запуск для отладки, `cargo build --release` — сборка (`target\release\lumen.exe`).
3. Установщик: установите Inno Setup 6, затем `iscc installer\lumen.iss` → `installer\Output\LumenSetup.exe`.
   Иконку добавьте через `SetupIconFile` в `lumen.iss`.

## Честные ограничения
- Код написан без запуска на Windows: возможны мелкие правки при первой сборке
  (API `wry` часто меняется, версии зафиксированы: `tao 0.30`, `wry 0.47`).
- Это оболочка над Chromium-движком, а не собственный движок.
- Блокировка по доменам, не по полным правилам EasyList (правила с путями и `$`-опциями пропускаются).
  Рекламу, вшитую в HTML-разметку статичными тегами, останавливает только CSS и блокировка навигации.
  Полноценная блокировка всех запросов делается через WebView2 `WebResourceRequested`
  (крейт `webview2-com`) — это следующий шаг.
- Горячие клавиши работают, когда фокус в панели интерфейса.
- Нет расширений, менеджера паролей, синхронизации, закладок и истории (хранение можно добавить через `rusqlite`).

## Сборка без установки Rust (GitHub Actions)
Загрузите проект в репозиторий GitHub (ветка `main`). Workflow `.github/workflows/build.yml`
соберёт `lumen.exe` и `LumenSetup.exe` на Windows-сервере. Скачать: вкладка Actions → последний запуск → Artifacts → `lumen-windows`.
Если сборка упадёт, пришлите текст ошибки — я исправлю код.

## Новое в этой версии
- **Усиленная блокировка рекламы**: движок Brave `adblock` + списки EasyList, RU AdList, AdGuard Russian, uBlock.
  Каждый запрос страницы проверяется через WebView2 (`WebResourceRequested`); пустые рекламные места скрываются косметическими правилами.
  Списки скачиваются в фоне в `%LOCALAPPDATA%\Lumen\filters\lists` (нужен `curl.exe` из Windows 10/11) и обновляются раз в 3 дня.
- **Память**: скрытые вкладки получают режим низкого потребления памяти, через минуту приостанавливаются, через 5 минут выгружаются
  (кроме сайтов с музыкой и видео). Можно переключить блокировку в «Базовую» — движок фильтров тогда выгружается из памяти.
- **Расширения** (🧩): установка из Chrome Web Store по ссылке или ID, включение, выключение и удаление.
- **Распознавание музыки** (🎵, Ctrl+M): запись 10 секунд звука системы (WASAPI loopback) или микрофона и поиск трека через AudD (нужен ключ API).

## Ещё новее
- Иконка (в окне, на панели задач, в exe и установщике), кнопки управления вынесены в одну строку со вкладками.
- Запуск: «Вернуть открытые вкладки» или «Новая вкладка» (Настройки → При запуске). Вернувшиеся вкладки не грузятся, пока вы их не откроете.
- Быстрые ссылки на стартовой странице (кнопка «+», звёздочка ☆ или Ctrl+D добавляют текущий сайт).
- Горячие клавиши работают и внутри страницы: Ctrl+T, Ctrl+W, Ctrl+Shift+T (вернуть закрытую), Ctrl+L / F6, Ctrl+Tab, Ctrl+1…9,
  Ctrl+H, Ctrl+, , Ctrl+M, Ctrl+D, Ctrl+Shift+N, Alt+← / Alt+→.
- Реклама: счётчик заблокированного и список последних запросов (Настройки → Блокировка рекламы), процедурные правила фильтров,
  скрытие карточек с пометкой «Реклама», запасные адреса для загрузки списков.

## Окна
- Вкладки в строке заголовка: у окна нет системной рамки, кнопки «свернуть / развернуть / закрыть» нарисованы в одной строке с вкладками.
  Окно двигается за пустое место строки, двойной щелчок разворачивает его; края окна тянутся мышью.
- Вкладку можно оторвать: потяните её вниз (или в сторону) от строки вкладок, она откроется во втором окне Lumen.
- Расширения с всплывающим окном открываются маленьким окном рядом с кнопкой (закрывается, когда вы щёлкаете в другом месте).
- Иконка: жёлтая лампочка.

## Память и скорость
- Скрытые вкладки: режим низкого потребления памяти → приостановка через минуту → выгрузка через 3/5/10 минут (настраивается).
- Вкладки одного сайта делят процесс; в «Эконом-режиме» дополнительно облегчённый режим Chromium и без кэша кнопки «Назад».
- Блокировщик перехватывает только запросы, которые могут быть рекламой (без стилей и шрифтов); частые обновления интерфейса склеиваются.
