Lumen — браузер с собственным интерфейсом и нативной логикой на **Rust**. Вкладки, управление окнами, горячие клавиши, настройки и интеграция с Windows реализованы на Rust. В Windows сайты отображает **Microsoft Edge WebView2** на основе Chromium, в Linux — **WebKitGTK**. Интерфейс браузера создан на HTML, CSS и JavaScript.

## Платформы

**Установка Linux из GitHub:** `git clone https://github.com/L4NOTTE/Lumen.git`, затем `cd Lumen` и `bash tools/install-linux.sh`. Зависимости, Rust и обновление через `git pull --ff-only` описаны в [LINUX.md](LINUX.md). Это текущий WebKitGTK preview, а не завершённая Chromium-версия.

**Windows x64** — основная версия. **Ubuntu 24.04 / Linux Mint 22.x x64** — первый Linux-порт (preview).

Linux использует другой движок: Chrome-расширения, Shazam/VK Next и оформление Chromium DevTools не перенесены. Linux-ветка подготовлена для сборки в Actions, но её нативный запуск на этой рабочей машине не проверен. Возможности, ограничения и получение `.deb` описаны в [LINUX.md](LINUX.md).

## Возможности Windows

- **Вкладки:** создание, восстановление закрытых вкладок, перестановка перетаскиванием и перенос между окнами. Ссылки средней кнопкой открываются в фоне.
- **Внешний вид:** светлая и тёмная темы, акцентные цвета, настройка шрифтов и фона новой вкладки.
- **Навигация:** адресная строка, выбор поисковика, история и быстрые ссылки.
- **Загрузки:** отдельный раздел по кнопке на панели или Ctrl + J; прогресс, отмена, поиск по истории, открытие файла и папки. Совпадающие имена получают числовой суффикс.
- **Масштаб:** кнопки на панели, горячие клавиши и Ctrl + колесо над страницей; значение сохраняется для каждого сайта между запусками.
- **DevTools** открывается из обычной вкладки кнопкой в панели браузера или клавишей F12. В Windows используется штатное окно WebView2, в Linux — инспектор WebKitGTK.
- **Блокировка рекламы:** сетевые фильтры и скрытие рекламных карточек, включая обработку закрытого Shadow DOM на Яндексе.
- **Расширения:** доступны в обычных окнах Windows. Восстановлены popup и адаптер захвата для Shazam.
- **Режимы работы:** инкогнито, усыпление неактивных вкладок и эконом-режим.

Совместимость расширений зависит от доступных API WebView2. Блокировка рекламы развивается: на отдельных сайтах объявления могут сохраняться. При переносе между окнами Windows сохраняет открытый WebView2 вкладки. Результаты проверок и известные ограничения собраны в [CHECKS.md](CHECKS.md).

## Запуск

1. Скачайте и распакуйте Windows-сборку.
2. Полностью закройте предыдущие окна Lumen и расширений.
3. Запустите `lumen.exe` либо используйте установщик `LumenSetup.exe`, если он входит в скачанную сборку.

Для работы нужны **Windows x64** и установленный **Microsoft Edge WebView2 Runtime**.

После обновления правил блокировки включите щит и скрытие рекламных меток в настройках, затем перезагрузите открытые страницы.

## Горячие клавиши

| Сочетание | Действие |
| --- | --- |
| Ctrl + T | Новая вкладка |
| Ctrl + W | Закрыть вкладку |
| Ctrl + Shift + T | Восстановить закрытую вкладку |
| Ctrl + Tab / Ctrl + Shift + Tab | Следующая / предыдущая вкладка |
| Ctrl + 1…9 | Перейти к вкладке по номеру |
| Ctrl + L / F6 | Выделить адресную строку |
| Alt + ← / Alt + → | Назад / вперёд |
| Ctrl + колесо | Изменить масштаб страницы |
| Ctrl + ↑ / Ctrl + ↓ | Увеличить / уменьшить масштаб |
| Ctrl + + / Ctrl + − | Увеличить / уменьшить масштаб |
| Ctrl + 0 | Сбросить масштаб |
| F12 / Ctrl + Shift + I | Открыть или закрыть боковые DevTools |
| F11 | Полноэкранный режим |
| Ctrl + H | История |
| Ctrl + J | Загрузки |
| Ctrl + Shift + N | Окно инкогнито |
| Ctrl + , | Настройки |

**Ctrl + Z** не используется для навигации: сочетание остаётся для отмены ввода в текстовых полях и редакторах сайтов.

Файлы сохраняются в системную папку загрузок. Очистка списка не удаляет файлы. История последних 200 загрузок сохраняется между запусками; инкогнито не записывает её на диск, но сами скачанные файлы остаются. При закрытии браузера активные загрузки прерываются; автоматическое возобновление пока не реализовано.

## Сборка из исходников

Стек проекта: **Rust · tao · wry · WebView2 · HTML/CSS/JavaScript**.

Команды выполняются на Windows из каталога с `Cargo.toml`, с установленным Rust stable и инструментами сборки MSVC:

```powershell
cargo test --locked
cargo build --release --locked
```

Готовый файл: `target/release/lumen.exe`.

Для проверки адаптера Shazam используется Node.js 22:

```powershell
node tools/test-shazam-capture.mjs
```

Для локальной сборки установщика нужен Inno Setup 6:

```powershell
iscc installer/lumen.iss
```

Установщик появится в `installer/Output/LumenSetup.exe`.

## Сборка через GitHub Actions

Загрузите **содержимое архива исходников** в корень репозитория, включая скрытую папку `.github`. Рядом с README должны находиться `Cargo.toml`, `Cargo.lock`, `src`, `ui` и остальные файлы проекта.

Workflow [build-windows](.github/workflows/build.yml) запускается при отправке изменений в `main` или вручную через **Actions → build-windows → Run workflow**. Он выполняет тесты, собирает браузер и установщик. После успешного завершения скачайте артефакт **lumen-windows** со страницы запуска.

## Что изменилось с 0.4.36

- **0.4.37.** Увеличены отступы в настройках, включая нижний край. Lumen предупреждает, если после скачивания файл отсутствует в папке загрузок.
- **0.4.38.** Когда WebView2 сообщает о блокировке, Lumen сразу показывает встроенное уведомление с именем файла и причиной.
- **0.4.39–0.4.41.** После получения всех байтов список показывает «Ожидание сохранения файла». Индикатор больше не округляет неполную загрузку до 100%. Предупреждение о зависшей почти завершённой загрузке появляется через 5 секунд без прогресса. Если файл уже сохранён под конечным именем, совпадает по размеру и закрыт для записи, Lumen может завершить запись в списке даже при запоздавшем статусе WebView2.
- **0.4.42.** Поток опроса загрузок спит при пустой очереди, отдельные окна переиспользуют уже отправленные иконки вкладок. Помощник автообновления запускает подписанный установщик только для более новой версии.
- **0.4.43.** Заменены зависимости, вызвавшие четыре предупреждения RustSec. Повторный аудит показал 0 известных уязвимостей и 0 предупреждений.

## Что нового в 0.4.43

- Удалены зависимости `fxhash`, `instant` и `proc-macro-error`. Генератор таблиц PHF использует `rand 0.8.8` вместо 0.7.3. Повторный аудит RustSec показал 0 известных уязвимостей и 0 предупреждений.
- В Windows прошли 34 теста и проверка защиты от поддельных команд веб-страниц. Изменённые пакеты для GTK3 скомпилированы отдельно. Нативный запуск Linux остаётся непроверенным.
- В сравнении с 0.4.20 и 0.4.30 медиана запуска 0.4.43 составила 511 мс против 602 и 552 мс. Частная память в простое составила 320,4 МиБ при одной вкладке. Локальные переходы быстрее всего прошли в 0.4.20.

[Аудит RustSec](audit.json) · [Сравнение производительности](comparison/REPORT.md)

- Внешний адрес принимается как `lumen.exe -- "https://example.com/"`, как обычный аргумент или через прежний `--url`. Регистрация не меняет UserChoice напрямую. Локальные HTML-файлы в ассоциации этого выпуска не добавлены.
- Подготовлена настройка будущего подписания EXE/установщика: [SIGNING.md](SIGNING.md). Пока сертификата нет, сборка остаётся неподписанной, и SmartScreen может показывать предупреждение.
